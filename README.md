# House Price Prediction using XGBoost

## Overview
This project predicts California house prices using XGBoost Regression.

## Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- XGBoost

## Results
- Train R² Score: 0.94
- Test R² Score: 0.83
- MAE: 0.31
